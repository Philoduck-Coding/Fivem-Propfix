# Fivem-Propfix

/propfix – Angehängte Props löschen

Mit dem Befehl /propfix kannst du angehängte Props an deinem Charakter entfernen. Dadurch werden beispielsweise Gegenstände gelöscht, die nach einer Animation oder einem Emote weiterhin an deiner Hand oder deinem Körper hängen.

Befehl: /propfix
